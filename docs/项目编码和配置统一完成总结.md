## 📄 创建的配置文件详解

### .editorconfig

**作用**：统一所有编辑器（VS Code, Visual Studio, Rider 等）的行为

**核心配置**：
```ini
[*]
charset = utf-8                  # ✅ 所有文件使用 UTF-8
end_of_line = crlf               # ✅ Windows 行尾
insert_final_newline = true      # ✅ 文件末尾插入空行
trim_trailing_whitespace = true  # ✅ 删除行尾空格

[*.cs]
indent_size = 4                  # ✅ C# 使用 4 空格缩进
indent_style = space             # ✅ 使用空格而非 Tab

[*.md]
indent_size = 2                  # ✅ Markdown 使用 2 空格缩进
```

**优势**：
- ✅ 跨编辑器统一配置
- ✅ 团队协作规范
- ✅ 自动应用设置
- ✅ Git 友好

### .vscode/settings.json

**作用**：VS Code 专用配置

**核心配置**：
```json
{
  "files.encoding": "utf8",              // ✅ 强制 UTF-8
  "files.autoGuessEncoding": false,      // ✅ 不自动猜测编码
  "files.eol": "\r\n",                   // ✅ Windows 行尾
  
  "[csharp]": {
    "files.encoding": "utf8",            // ✅ C# 文件强制 UTF-8
    "editor.formatOnSave": true          // ✅ 保存时自动格式化
  },
  
  "[markdown]": {
    "files.encoding": "utf8",            // ✅ Markdown 强制 UTF-8
    "editor.wordWrap": "on"              // ✅ 自动换行
  }
}
```

**优势**：
- ✅ VS Code 用户开箱即用
- ✅ 自动格式化
- ✅ 智能提示优化
- ✅ 文件编码可见

## 🎯 CI/CD 集成

### GitHub Actions 示例

```yaml
name: Check File Encoding

on: [push, pull_request]

jobs:
  check-encoding:
    runs-on: windows-latest
    steps:
      - uses: actions/checkout@v3
      
      - name: Check UTF-8 BOM
        shell: pwsh
        run: |
          $files = Get-ChildItem -Recurse -Include *.cs,*.md,*.csproj
          $hasBom = $false
          
          foreach ($file in $files) {
            $bytes = Get-Content $file.FullName -Encoding Byte -ReadCount 3 -TotalCount 3
            if ($bytes[0] -eq 0xef -and $bytes[1] -eq 0xbb -and $bytes[2] -eq 0xbf) {
              Write-Error "File has BOM: $($file.FullName)"
              $hasBom = $true
            }
          }
          
          if ($hasBom) {
            exit 1
          }
          
          Write-Host "✓ All files are UTF-8 without BOM"
```

## 🔍 常见问题

### Q1: 为什么要统一文件编码？

**答**: 
- ✅ 避免乱码问题（特别是 NuGet README 显示）
- ✅ 团队协作一致性
- ✅ Git diff 更清晰
- ✅ 跨平台兼容

### Q2: UTF-8 BOM 和 UTF-8 无 BOM 有什么区别？

**答**:
- **UTF-8 BOM**: 文件开头有 3 个字节 `EF BB BF`
- **UTF-8 无 BOM**: 文件直接以内容开始
- **推荐**: UTF-8 无 BOM（兼容性更好）

### Q3: 如何检查文件编码？

**答**:
```powershell
# PowerShell 命令
$bytes = [byte[]](Get-Content "file.cs" -Encoding Byte -ReadCount 4 -TotalCount 4)
if ($bytes[0] -eq 0xef -and $bytes[1] -eq 0xbb -and $bytes[2] -eq 0xbf) {
    Write-Host "UTF-8 BOM"
} else {
    Write-Host "UTF-8 无 BOM"
}
```

或在 VS Code 中查看右下角编码显示。

### Q4: 如何防止未来出现编码问题？

**答**:
1. ✅ 使用 `.editorconfig`（自动应用）
2. ✅ 配置 VS Code/Visual Studio 默认编码
3. ✅ 定期运行编码检查脚本
4. ✅ CI/CD 自动化验证
