# 转换、空值与诊断策略

`source.Adapt<TDestination>()` 保持不变。根值、成员和集合元素共享相同的转换定义；不再因成员不支持而跳过，或在集合失败时偷偷加入 null。

## 转换优先级

1. 类型相同或实际值可直接赋给目标：直接赋值，包括对象与集合。不是深拷贝，同型映射也不会借转换规则替换原对象。
2. 已注册的类型转换：精确类型对优先。非 null 的可空值如无精确规则，可复用底层类型规则；null 不作为底层默认值传进规则。
3. 常见标量转换：数字、字符串、枚举、可空类型、Guid、DateTime、DateTimeOffset、DateOnly、TimeOnly、TimeSpan 等。
4. 对象和集合走对应映射；不支持、格式错误或溢出抛出 MappingException。自定义规则可明确处理 JSON、加密字节等特殊含义。

ForMember 指定成员来源表达式，Rename 指定源属性或嵌套路径，Ignore 决定是否映射。它们不等同于类型转换器。复杂对象不能仅凭 IConvertible 或任意 ToString 就视为普通标量。

目标选择器目前仅支持直接属性（`d => d.Child`），不支持 `d => d.Child.Value`，后者在配置时明确拒绝。源路径 `Rename(d => d.Value, "A.B.Value")` 仍支持；需要自定义嵌套目标时配置整个 Child 对象。不同字典类型、不可写/空结构体不能用普通属性映射伪造默认键值，必须配置显式规则；相同或可安全赋值的字典仍直接赋值。ReverseMap 和全局约定占位不视为已经完成的自动反向/约定映射功能，详见覆盖矩阵。

示例：`123.45m → "123.45"`、`"123.45" → 123.45m`；`"abc" → decimal` 抛异常，不能变成 0。数字采用 Convert 的舍入与溢出语义：浮点/decimal 转整数可能进行银行家舍入，不能假定截断；整数与 decimal 超范围报错而非静默回绕；浮点转换保持 .NET Convert/解析语义，可能产生 Infinity，并允许 NaN/Infinity。需要只接受有限浮点数的业务应配置显式转换规则，库不承诺所有浮点溢出都抛异常。枚举按底层类型转换，名称忽略大小写，保留标准 Enum.Parse 对数值与 Flags 的语义，不自动强制 Enum.IsDefined。

## 文化区域与时区

数字及日期字符串使用 InvariantCulture，不取服务器 CurrentCulture。日期字符串与数字之间不猜测 ticks、Unix 秒或毫秒，需要显式注册规则。

- DateTime 输出使用 `O`；字符串无偏移时保留 Unspecified，明确 Z/偏移时归一到 UTC。
- DateTimeOffset 输出使用 `O`；字符串无偏移时默认 UTC，明确偏移时保留该偏移。
- DateOnly、TimeOnly 输出使用 `O`；TimeSpan 使用 `c`。

统一文化区域不等于统一时区，因此回归还需在多个 TZ 的独立进程执行，不能只改 CurrentCulture。

## 空值单独处理

```csharp
var configuration = new MapperConfiguration
{
    NullValueHandling = NullValueHandling.UseDefault // 默认，null → int 得到 0
};
// 若要拒绝 null → 非可空值类型：
configuration.NullValueHandling = NullValueHandling.Throw;
```

null 到可空类型或引用类型仍为 null；IgnoreNullValues 表示跳过该成员赋值，而不是把转换失败当 null。空字符串不是 null，非法字符串仍需报错。

通用 `Adapt<T>(null)` 与 IMapper 使用同一空值策略，不再自动创建一个空 DTO；通用 `Adapt<List<T>>(null)` 返回 null。显式的 `IEnumerable<TSource>.Adapt<TTarget,TSource>(itemCallback)` 集合项回调重载保留原有 null→空列表行为。这项区分有独立回归，不应把空源、空集合和转换失败混用。

无公开无参构造函数的普通对象目标保留现有 StrictMode 行为：非严格模式的 IMapper.Map 返回 null，严格模式报错；Adapt 的既有 fallback 也可能因此报构造异常。StrictMode 不表示所有未匹配属性都必须报错。字段未匹配与字段值转换失败是不同情况。

## 失败诊断

MappingException 提供 SourceType、DestinationType、Path、OriginalExceptionType 与可选的 SourceValue 预览，例如 `$.Orders[2].Amount`。不是整个源对象的快照。

```csharp
var configuration = new MapperConfiguration
{
    IncludeSourceValueInExceptions = true,
    MaxDiagnosticValueLength = 128
};
```

默认不输出值。开启后普通标量值最多指定长度，并移除换行；Password、Token、Secret、加密相关路径及 byte[]、复杂对象仍脱敏。Rename 的敏感来源也必须纳入检查。字段名识别不是通用数据分类器，敏感业务字段应保持默认关闭或采用明确规则。

诊断长度为 0 合法，普通值预览为空；负数及未定义的 NullValueHandling 在 CreateMapper 时拒绝。仅当错误发生时才格式化预览，不在正常转换路径构造异常文本。

内部异常的原始 message、Data、inner 链可能含完整值，因此不直接保留原异常对象。InnerException 为安全类型摘要，OriginalExceptionType 保留原异常类型名。这意味着不能将 InnerException 强制转换为原 FormatException；此边界是为了避免外层脱敏但日志 ToString 又泄露原值。第三方转换器内部主动输出的日志不在映射库控制范围内。

## 并发与缓存

同一个已创建 Mapper 可并发映射，每个顶层调用拥有独立上下文；同一次对象图内保留受支持的循环与共享引用，不把上一次映射结果缓存为下一次结果。不能预创建的构造型集合遇循环应明确报错，不无限递归。

MapperConfiguration、Profile 在 CreateMapper 前完成配置，之后不要并发修改。TypeConverterRegistry 可替换规则，随后新调用重新构建受影响的缓存代；正在进行的映射不承诺与规则替换形成整个对象图的原子事务。不要在请求循环里不断注册相同规则，以免反复失效缓存。

结果回调 `Adapt<T>(Action<T>)` 在最终结果上调用一次；集合项回调在各映射项上执行。直接赋值不代表复制对象。整体集合由自定义转换器完全接管时，规则负责其内部元素行为，不将它误称为逐项映射。

## 验证边界

转换矩阵、异常安全、缓存与并发都要检查实际输出。测试通过不自动证明任意复杂类型、Native AOT 或所有第三方转换器正确；详见[架构与 AOT](架构与AOT.md)以及[回归入口](../tests/Ling.Mapper.Tests/README.md)。
