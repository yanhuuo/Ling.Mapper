# 转换、空值与诊断策略

`source.Adapt<TDestination>()` 保持不变。根值、成员和集合元素共享相同的转换定义；不再因成员不支持而跳过，或在集合失败时偷偷加入 null。

## 转换优先级

1. 无非空忽略投影、也没有该类型对的显式成员规则时，安全可赋值的不可变原子直接赋值。可变对象/集合不再有 identity 快捷返回，默认映射独立图。
2. 若进入映射，已注册的**整体类型转换器**优先，接管该类型对的全部转换。精确类型对优先；非 null 可空值无精确规则时可复用底层规则，null 不传进规则。整体 converter 与 Profile 同时配置时，Profile 不执行。
3. 显式对象类型对配置使用其字段映射，不被自动发现的 `implicit` / `explicit` 运算符绕过。字段映射内部是 Ignore → ForMember → Rename → 同名约定；ForMember/MapFrom 先求值一次，复杂返回值继续映射；明确 member ConvertUsing 返回最终值，不再执行同型映射。
4. 没有显式类型对配置时，使用源或目标类型上唯一、精确匹配的公开静态用户定义 `implicit` / `explicit` 运算符。
5. 常见标量转换：数字、字符串、枚举、可空类型、Guid、DateTime、DateTimeOffset、DateOnly、TimeOnly、TimeSpan 等。
6. 其余对象和集合走对应映射；不支持、格式错误或溢出抛出 MappingException。自定义规则可明确处理 JSON、加密字节等特殊含义。

同型映射（包括无配置及空 Profile）默认创建独立可变图；显式规则仍生效。规则/原子/资源边界和 breaking changes 见[独立图契约](independent-graphs.md)。配置必须在 CreateMapper 前完成，创建后修改 Profile 不属于受支持的热更新方式。

`ForMember` 指定成员来源表达式，`Rename` 指定源属性或嵌套路径，`Ignore` 决定是否映射；它们不等同于整体类型转换器。结果/元素 callback 是**映射成功后**执行，不能用它阻止此前已经失败的自动字段转换；需要替换字段转换时应使用 ForMember，或先 Ignore 再在 callback 中赋值。复杂对象不能仅凭 IConvertible 或任意 ToString 就视为普通标量。

ForMember、Rename、Ignore 支持嵌套目标路径。泛型字典逐项映射键和值，key 冲突或 null 明确失败；异常使用 `[i].Key` / `[i].Value`，不把真实 key 放进路径或预览。不可变结构体通过唯一可绑定公开构造函数建立，不能静默产出全默认字段。ReverseMap 只自动反转 Rename/纯属性路径；计算表达式明确拒绝，需两条显式 CreateMap。详见[使用文档](使用文档.md)。

非空忽略投影作用于独立映射结果；整个类型的显式 converter 与该投影组合明确拒绝，避免忽略被静默丢弃。引用缓存按源身份、声明目标类型及投影区分；显式 Profile（包括空配置）参与时还隔离有效声明源类型对，避免同一对象经不同 Profile 被错误复用。无显式规则的普通对象图保留原有共享/循环语义。此规则不意味着接口/具体类型之间的目标实例也自动合并。

示例：`123.45m → "123.45"`、`"123.45" → 123.45m`；`"abc" → decimal` 抛异常，不能变成 0。数字采用 Convert 的舍入与溢出语义：浮点/decimal 转整数可能进行银行家舍入，不能假定截断；整数与 decimal 超范围报错而非静默回绕；浮点转换保持 .NET Convert/解析语义，可能产生 Infinity，并允许 NaN/Infinity。需要只接受有限浮点数的业务应配置显式转换规则，库不承诺所有浮点溢出都抛异常。枚举按底层类型转换，名称忽略大小写，保留标准 Enum.Parse 对数值与 Flags 的语义，不自动强制 Enum.IsDefined。

## 文化区域与时区

本轮按用户明确选择，将数字及金额字符串的默认格式化/解析从 InvariantCulture 改为 **CurrentCulture**，不保留旧默认兼容开关。日期文本继续跟随 CurrentCulture 和本机时区；这与 1.2.0 最初的 ISO / UTC 默认行为不同。日期字符串与数字之间仍不猜测 ticks、Unix 秒或毫秒，需要显式注册规则。

- 每次转换读取当前 culture，不把首次调用的 culture 缓存在映射计划里；同一 mapper 可在不同异步请求的 culture 下使用。`1234.56m` 在 en-US 格式化为 `"1234.56"`，在 de-DE/fr-FR 为 `"1234,56"`；解析采用 .NET Convert 的当前文化分隔符规则，不能假定另一区域的点号必定是小数点。
- 用户 ForMember/注册 converter 内显式传入 `InvariantCulture` 或其他 provider 的代码保持原样；库不重写或覆盖用户的文化选择。固定协议/文件格式应使用显式转换规则。
- DateTime、DateTimeOffset、DateOnly、TimeOnly、TimeSpan 转字符串调用无参 `ToString()`，不强制 ISO `O`。默认格式可能省略小数秒、秒或 Kind 信息，不保证无损往返。
- 字符串转 DateTime 使用 `Convert.ToDateTime(string)`：无偏移输入通常为 Unspecified；明确 Z / 偏移按默认解析转换到本机时区，通常为 Local，而非强制 UTC。
- 字符串转 DateTimeOffset 使用无参 `Parse`：无偏移输入采用本机偏移，有明确偏移则保留。
- DateOnly、TimeOnly、TimeSpan 解析采用无参 `Parse`。DateOnly / TimeOnly 的字符串解析是 Ling.Mapper 保留的扩展，不应声称 AutoMapper 所有版本原生支持。
- `01/02/2026` 等歧义日期的解释取决于 CurrentCulture；跨服务器需要稳定协议时，请显式注册固定格式、文化区域和时区规则。

保持现有统一 null 策略及 MappingException 契约，不为复刻第三方某个非泛型 null 入口而改变所有空值行为。日期格式兼容不表示全部 API 语义与 AutoMapper 完全等同。回归应同时覆盖多个文化区域及不同 TZ 的独立进程，不能只改 CurrentCulture。

## 用户定义转换运算符与 EnumMember

运行时识别源或目标类型声明的公开静态 `op_Implicit` / `op_Explicit`，先选择参数与返回类型完整匹配的声明（包括明确声明的 nullable 签名）；没有精确对时只允许 nullable 参数提升/底层值转换及结果提升到 nullable，不自动拆开 nullable 返回结果到非 nullable 目标。声明为 nullable 的成员、集合元素和 Type 入口保留该类型信息；仅传入 object 的非 null nullable 值被 CLR 装箱后无法恢复原声明，可使用 Type 入口。不串联多次运算符、不补数字强转、不搜索任意单参数构造函数；多个匹配候选明确报错，使用整体 converter 消歧。仅含既有内置标量的类型对不改用运算符，因此 decimal→int 仍是 Convert 的银行家舍入及溢出检查。自动运算符的异常不属于 ForMember 来源表达式 null 回退范围；忽略投影不能穿透不透明运算符，会明确拒绝。

`[EnumMember(Value = "in-progress")] Active` 为 enum↔string 增加忽略大小写的别名：字符串接受别名及原 CLR 名称，格式化使用别名。Flags 组合逐项处理别名，已命名组合优先使用其完整别名；未定义值仍保持标准数值文本，enum→enum 仍按底层数值，而不是按名称配对。

为防止静默歧义，别名与其他真实枚举名称/数字/Flags 表达式或其他别名冲突且对应不同值时，enum↔string 明确失败；不能用别名掩盖底层数字溢出。相同值的重复别名可用。null Value 属性不改变默认行为；空白/空别名、首尾空白以及 Flags 别名中的逗号被拒绝。普通非 Flags 的完整别名可包含逗号。空字符串不会因为别名机制自动变成默认枚举。

这些是 Ling 的受限能力，不声称与 AutoMapper/Mapster 全部转换行为相同。生成器的静态运算符支持范围及 enum 元数据保留见[生成器说明](../generators/Ling.Mapper.Generator/README.md)；运行时通过不代表 Native AOT 已验证。

## 空值单独处理

```csharp
var configuration = new MapperConfiguration
{
    NullValueHandling = NullValueHandling.UseDefault // 默认，null → int 得到 0
};
// 若要拒绝 null → 非可空值类型：
configuration.NullValueHandling = NullValueHandling.Throw;
```

null 到可空类型或引用类型仍为 null；IgnoreNullValues 表示跳过该成员赋值，而不是把转换失败当 null。空字符串不是 null，非法字符串仍需报错。

通用 `Adapt<T>(null)` 与 IMapper 使用同一空值策略，不再自动创建一个空 DTO；通用 `Adapt<List<T>>(null)` 返回 null。显式的 `IEnumerable<TSource>.Adapt<TTarget,TSource>(itemCallback)` 集合项回调重载保留原有 null→空列表行为。这项区分有独立回归，不应把空源、空集合和转换失败混用。

无公开无参构造函数的普通对象目标保留现有 StrictMode 行为：非严格模式的 IMapper.Map 返回 null，严格模式报错；通用 Adapt 保留 mapper 返回的 null，不再通过 fallback 反射构造目标；显式集合项回调重载保留空列表约定。StrictMode 不表示所有未匹配属性都必须报错。字段未匹配与字段值转换失败是不同情况。

## 失败诊断

MappingException 提供 SourceType、DestinationType、Path、OriginalExceptionType 与可选的 SourceValue 预览，例如 `$.Orders[2].Amount`。不是整个源对象的快照。

```csharp
var configuration = new MapperConfiguration
{
    IncludeSourceValueInExceptions = true,
    MaxDiagnosticValueLength = 128
};
```

默认不输出值。开启后普通标量值最多指定长度，并移除换行；Password、Token、Secret、加密相关路径及 byte[]、复杂对象仍脱敏。Rename 的敏感来源也必须纳入检查。字段名识别不是通用数据分类器，敏感业务字段应保持默认关闭或采用明确规则。

诊断长度为 0 合法，普通值预览为空；负数及未定义的 NullValueHandling 在 CreateMapper 时拒绝。仅当错误发生时才格式化预览，不在正常转换路径构造异常文本。

内部异常的原始 message、Data、inner 链可能含完整值，因此不直接保留原异常对象。InnerException 为安全类型摘要，OriginalExceptionType 保留原异常类型名。这意味着不能将 InnerException 强制转换为原 FormatException；此边界是为了避免外层脱敏但日志 ToString 又泄露原值。第三方转换器内部主动输出的日志不在映射库控制范围内。

## 并发与缓存

同一个已创建 Mapper 可并发映射，每个顶层调用拥有独立上下文；同一次对象图内保留受支持的循环与共享引用，不把上一次映射结果缓存为下一次结果。不能预创建的构造型集合遇循环应明确报错，不无限递归。

MapperConfiguration、Profile 在 CreateMapper 前完成配置，之后不要并发修改。TypeConverterRegistry 可替换规则，随后新调用重新构建受影响的缓存代；正在进行的映射不承诺与规则替换形成整个对象图的原子事务。不要在请求循环里不断注册相同规则，以免反复失效缓存。

结果回调 `Adapt<T>(Action<T>)` 在最终结果上调用一次；集合项回调在各映射项上执行。只有不可变原子可自动直接赋值。整体集合由自定义转换器完全接管时，规则负责其内部元素行为，不将它误称为逐项映射。

## 验证边界

转换矩阵、异常安全、缓存与并发都要检查实际输出。测试通过不自动证明任意复杂类型、Native AOT 或所有第三方转换器正确；详见[架构与 AOT](架构与AOT.md)以及[回归入口](../tests/Ling.Mapper.Tests/README.md)。


## 自定义表达式的 null 异常兼容（1.3.1，待手动发布）

`ForMember` 的**来源表达式求值阶段**现在兼容 AutoMapper expression-based `MapFrom` 的 null 异常回退：`NullReferenceException` 或 `ArgumentNullException` 返回表达式类型的默认值（引用/nullable 为 null，非 nullable 值类型为 default）。这也包含自定义方法主动抛出的这两类异常；它不是对任意调用参数自动做语义判空。此边界覆盖普通成员、嵌套目标路径，以及既有的不可变结构体构造参数来源表达式。

- 显式 `s => s.Bytes == null ? "fallback" : Decode(s.Bytes)` 仍完整执行，fallback 不会被跳过。
- `IgnoreNullValues` 在表达式成功求值或上述回退之后判断结果，只跳过 null 结果的可写成员赋值，保留目标初始化器；不会跳过非 null fallback。不可变构造参数没有可跳过的赋值，仍传入解析结果，并不保留可选参数默认值。
- 格式错误、溢出、`Nullable<T>.Value` 为空导致的 `InvalidOperationException` 和其他业务异常不会被此策略吞掉，仍有 `MappingException.OriginalExceptionType` 与成员/集合路径。
- 普通自动 getter、注册转换器、目标构造函数、setter 与 after-map 回调不在此回退范围内。
- 生成器不解释 runtime Profiles；不能由此推断生成模式支持 ForMember。运行时现已新增 PreCondition、Condition、NullSubstitute、ConvertUsing 与已有目标更新；这些不是生成 Profile 支持。

金额 `decimal? → int?` 保持已存在的 `Convert.ToInt32` 默认语义：null 保留 null；1.00→1、1.5→2、2.5→2，超出 Int32 范围报错。不需要 `int.Parse(value.ToString())`。同名字段直接自动转换；异名使用 `Rename`；自定义规则可明确写为 `s => s.Amount.HasValue ? (int?)Convert.ToInt32(s.Amount.Value) : null`。不要将格式/溢出错误转成零。
