# ?? 全局配置和运行时选项完整指南

## ?? 概述

Ling.Mapper 提供**两种**配置方式来控制映射行为：

1. **全局配置**：在创建 Mapper 时设置，对所有映射生效
2. **运行时选项**：在每次映射时单独指定，只对当前映射生效

---

## 1?? 全局配置（GlobalConventionOptions）

### ?? 配置项

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `CaseInsensitiveNameMatch` | `bool` | `true` | 忽略属性名称大小写 |
| `IgnoreSpecialCharacters` | `bool` | `false` | 忽略特殊字符（如下划线） |

### ?? 配置方式

```csharp
using Ling.Mapper;

// 创建 Mapper 配置
var config = new MapperConfiguration();

// 配置全局约定
config.ConfigureConventions(opt => 
{
    // 忽略大小写（默认已启用）
    opt.CaseInsensitiveNameMatch = true;
    
    // 忽略特殊字符（如下划线）
    opt.IgnoreSpecialCharacters = true;
});

// 创建 Mapper
var mapper = config.CreateMapper();

// 设置为全局 Mapper（可选）
MapperProvider.SetCurrent(mapper);
```

### ?? 使用示例

#### 示例 1: 忽略大小写匹配

```csharp
// 源类型
public class SourceDto
{
    public string firstname { get; set; }  // 小写
    public string LASTNAME { get; set; }   // 大写
}

// 目标类型
public class TargetDto
{
    public string FirstName { get; set; }  // 首字母大写
    public string LastName { get; set; }   // 首字母大写
}

// 配置（启用大小写不敏感）
var config = new MapperConfiguration();
config.ConfigureConventions(opt => 
{
    opt.CaseInsensitiveNameMatch = true;  // ? 默认已启用
});

var mapper = config.CreateMapper();

// 映射（自动匹配不同大小写的属性）
var target = mapper.Map<TargetDto>(source);
// ? firstname → FirstName
// ? LASTNAME → LastName
```

#### 示例 2: 忽略下划线

```csharp
// 数据库字段（带下划线）
public class DbRow
{
    public string user_name { get; set; }
    public string first_name { get; set; }
    public string last_name { get; set; }
}

// C# 类（驼峰命名）
public class User
{
    public string UserName { get; set; }
    public string FirstName { get; set; }
    public string LastName { get; set; }
}

// 配置（忽略下划线）
var config = new MapperConfiguration();
config.ConfigureConventions(opt => 
{
    opt.CaseInsensitiveNameMatch = true;   // 忽略大小写
    opt.IgnoreSpecialCharacters = true;    // 忽略下划线
});

var mapper = config.CreateMapper();

// 映射（自动匹配）
var user = mapper.Map<User>(dbRow);
// ? user_name → UserName
// ? first_name → FirstName
// ? last_name → LastName
```

#### 示例 3: 完整配置示例

```csharp
// Program.cs 或 Startup.cs
public void ConfigureMapper()
{
    var config = new MapperConfiguration();
    
    // 1. 添加 Profile
    config.AddProfile(new UserProfile());
    config.AddProfile(new OrderProfile());
    
    // 2. 配置全局约定
    config.ConfigureConventions(opt => 
    {
        opt.CaseInsensitiveNameMatch = true;    // 忽略大小写
        opt.IgnoreSpecialCharacters = true;     // 忽略下划线
    });
    
    // 3. 设置严格模式（可选）
    config.StrictMode = false;  // 允许未匹配的属性
    
    // 4. 创建并设置全局 Mapper
    var mapper = config.CreateMapper();
    MapperProvider.SetCurrent(mapper);
}
```

## 2?? 运行时选项（AdaptOptions）

### ?? 配置项

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `IgnoreCase` | `bool` | `false` | 忽略属性名称大小写 |
| `IgnoreUnderscore` | `bool` | `false` | 忽略属性名称中的下划线 |
| `IgnoreProperties` | `string[]?` | `null` | 忽略指定的属性列表 |
| `IgnoreNullValues` | `bool` | `false` | 忽略 null 值属性 |

### ?? 预定义选项

```csharp
// 1. 默认选项（无特殊处理）
AdaptOptions.Default

// 2. 忽略大小写
AdaptOptions.IgnoreCaseOption

// 3. 忽略下划线
AdaptOptions.IgnoreUnderscoreOption

// 4. 灵活选项（忽略大小写 + 下划线）
AdaptOptions.FlexibleOption
```

### ?? 使用示例

#### 示例 1: 使用预定义选项

```csharp
// 忽略大小写
var target = source.Adapt<TargetDto>(AdaptOptions.IgnoreCaseOption);

// 忽略下划线
var target = dbRow.Adapt<User>(AdaptOptions.IgnoreUnderscoreOption);

// 灵活选项（大小写 + 下划线）
var target = apiData.Adapt<Model>(AdaptOptions.FlexibleOption);
```

#### 示例 2: 自定义选项

```csharp
// 创建自定义选项
var options = new AdaptOptions
{
    IgnoreCase = true,
    IgnoreUnderscore = true,
    IgnoreProperties = new[] { "Password", "CreditCard" },
    IgnoreNullValues = true
};

// 使用自定义选项映射
var target = source.Adapt<TargetDto>(options);
```

#### 示例 3: 配合回调使用

```csharp
var target = source.Adapt<TargetDto>(
    AdaptOptions.FlexibleOption,
    (dest, src) => 
    {
        // 在映射后进行额外处理
        dest.FullName = $"{src.FirstName} {src.LastName}";
        dest.CreatedAt = DateTime.Now;
    });
```

#### 示例 4: 实际应用场景

```csharp
// 场景 1: API 响应（忽略大小写）
var users = apiResponse.Adapt<List<UserDto>>(AdaptOptions.IgnoreCaseOption);

// 场景 2: 数据库映射（忽略下划线）
var products = dbRows.Adapt<List<Product>>(AdaptOptions.IgnoreUnderscoreOption);

// 场景 3: 第三方 API（灵活匹配）
var orders = externalData.Adapt<List<Order>>(AdaptOptions.FlexibleOption);

// 场景 4: 敏感信息处理
var userProfile = source.Adapt<UserProfile>(new AdaptOptions
{
    IgnoreCase = true,
    IgnoreProperties = new[] { "Password", "SSN", "CreditCard" }
});
```

## 3?? 全局配置 vs 运行时选项

### 对比表

| 特性 | 全局配置 | 运行时选项 |
|------|---------|-----------|
| **作用范围** | 所有映射 | 单次映射 |
| **配置时机** | 创建 Mapper 时 | 调用 Adapt 时 |
| **优先级** | 低 | 高 |
| **灵活性** | 低（固定） | 高（动态） |
| **性能** | 高（编译时优化） | 中（运行时处理） |
| **适用场景** | 统一的命名规范 | 特殊情况处理 |

### 优先级规则

```csharp
// 1. 全局配置
config.ConfigureConventions(opt => 
{
    opt.CaseInsensitiveNameMatch = true;    // 全局忽略大小写
});

// 2. 运行时选项（会覆盖全局配置）
var target = source.Adapt<TargetDto>(new AdaptOptions
{
    IgnoreCase = false  // 此次映射不忽略大小写（覆盖全局配置）
});
```

### 推荐使用场景

#### 使用全局配置的场景

```csharp
// ? 统一的数据库字段命名（全部带下划线）
config.ConfigureConventions(opt => 
{
    opt.IgnoreSpecialCharacters = true;  // 全局忽略下划线
});

// ? 统一的 API 响应格式（全部小写）
config.ConfigureConventions(opt => 
{
    opt.CaseInsensitiveNameMatch = true;  // 全局忽略大小写
});
```

#### 使用运行时选项的场景

```csharp
// ? 特定的第三方 API（大小写不一致）
var data = externalApi.Adapt<Model>(AdaptOptions.FlexibleOption);

// ? 临时忽略敏感属性
var dto = user.Adapt<UserDto>(new AdaptOptions
{
    IgnoreProperties = new[] { "Password", "Email" }
});

// ? 不同数据源的特殊处理
var dbData = dbRow.Adapt<Model>(AdaptOptions.IgnoreUnderscoreOption);
var apiData = apiResponse.Adapt<Model>(AdaptOptions.IgnoreCaseOption);
```

## 4?? 完整示例

### 示例 1: 多数据源映射

```csharp
// 1. 配置全局 Mapper
var config = new MapperConfiguration();
config.ConfigureConventions(opt => 
{
    opt.CaseInsensitiveNameMatch = true;  // 默认忽略大小写
});

var mapper = config.CreateMapper();
MapperProvider.SetCurrent(mapper);

// 2. 数据库映射（需要忽略下划线）
var users = dbContext.Users
    .ToList()
    .Adapt<List<UserDto>>(AdaptOptions.IgnoreUnderscoreOption);

// 3. API 映射（使用全局配置）
var products = apiClient.GetProducts()
    .Adapt<List<ProductDto>>();  // 自动应用全局的忽略大小写

// 4. 第三方 API（需要灵活匹配）
var orders = externalApi.GetOrders()
    .Adapt<List<OrderDto>>(AdaptOptions.FlexibleOption);
```

### 示例 2: 分页数据处理

```csharp
public async Task<PageResult<UserDto>> GetUserPage(int page, int size)
{
    // 1. 查询数据库（字段名带下划线）
    var dbResult = await _dbContext.Users
        .Skip((page - 1) * size)
        .Take(size)
        .ToListAsync();
    
    // 2. 映射为 DTO（忽略下划线 + 自定义处理）
    var users = dbResult.Adapt<List<UserDto>>(
        AdaptOptions.IgnoreUnderscoreOption,
        (dest, src) => 
        {
            // 对映射结果进行额外处理
            for (int i = 0; i < dest.Count; i++)
            {
                dest[i].RowNumber = (page - 1) * size + i + 1;
                dest[i].DisplayName = FormatName(dest[i]);
            }
        });
    
    return new PageResult<UserDto>
    {
        Page = page,
        Size = size,
        Total = await _dbContext.Users.CountAsync(),
        Data = users
    };
}
```

### 示例 3: 多 Profile 配置

```csharp
// UserProfile.cs
public class UserProfile : MapperProfile
{
    public UserProfile()
    {
        CreateMap<User, UserDto>()
            .ForMember(d => d.FullName, s => s.FirstName + " " + s.LastName);
    }
}

// Startup.cs
public void ConfigureServices(IServiceCollection services)
{
    // 配置 Mapper
    var config = new MapperConfiguration();
    
    // 添加 Profiles
    config.AddProfile(new UserProfile());
    config.AddProfile(new OrderProfile());
    
    // 全局约定
    config.ConfigureConventions(opt => 
    {
        opt.CaseInsensitiveNameMatch = true;
        opt.IgnoreSpecialCharacters = true;
    });
    
    // 注册到 DI
    services.AddFluentMapper(config);
}

// Controller.cs
public class UserController : ControllerBase
{
    private readonly IMapper _mapper;
    
    public UserController(IMapper mapper)
    {
        _mapper = mapper;
    }
    
    [HttpGet]
    public async Task<IActionResult> GetUsers()
    {
        var users = await _repository.GetAllAsync();
        
        // 使用注入的 Mapper
        var dtos = users.Adapt<List<UserDto>>(_mapper);
        
        return Ok(dtos);
    }
}
```

## 5?? 常见问题

### Q1: 全局配置和运行时选项可以同时使用吗？

**答**: 可以。运行时选项的优先级更高。

```csharp
// 全局配置：忽略大小写
config.ConfigureConventions(opt => opt.CaseInsensitiveNameMatch = true);

// 运行时选项：不忽略大小写（覆盖全局配置）
var target = source.Adapt<TargetDto>(new AdaptOptions { IgnoreCase = false });
```

### Q2: 如何同时忽略大小写和下划线？

**答**: 有两种方式。

```csharp
// 方式 1: 全局配置
config.ConfigureConventions(opt => 
{
    opt.CaseInsensitiveNameMatch = true;
    opt.IgnoreSpecialCharacters = true;
});

// 方式 2: 运行时选项（使用预定义的 FlexibleOption）
var target = source.Adapt<TargetDto>(AdaptOptions.FlexibleOption);
```

### Q3: AdaptOptions 对性能有影响吗？

**答**: 有轻微影响，但可以接受。

- **全局配置**: 在编译映射时优化，性能最优
- **运行时选项**: 在运行时处理，有轻微性能开销
- **建议**: 对于固定的命名规范，使用全局配置；对于特殊情况，使用运行时选项

### Q4: 为什么全局配置的 CaseInsensitiveNameMatch 默认是 true？

**答**: 因为大多数场景下，开发者希望忽略大小写差异。如果需要严格匹配，可以设置为 `false`：

```csharp
config.ConfigureConventions(opt => 
{
    opt.CaseInsensitiveNameMatch = false;  // 严格匹配大小写
});
```

### Q5: 如何处理既有大小写差异又有下划线的情况？

**答**: 使用 `FlexibleOption`：

```csharp
// 源数据（混合命名）
public class ApiResponse
{
    public string USER_NAME { get; set; }    // 大写 + 下划线
    public string first_name { get; set; }   // 小写 + 下划线
}

// 目标类型（驼峰命名）
public class User
{
    public string UserName { get; set; }
    public string FirstName { get; set; }
}

// 使用 FlexibleOption
var user = apiResponse.Adapt<User>(AdaptOptions.FlexibleOption);
```
