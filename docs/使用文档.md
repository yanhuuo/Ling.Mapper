## 简介

Ling.Mapper 是一个高性能、零配置的 .NET 对象映射库，基于 Expression Tree 编译技术实现，提供接近手写代码的映射性能。

### 核心特性

- ✅ **零配置映射** - 自动匹配同名属性，开箱即用
- ✅ **高性能** - 基于表达式树编译，运行时性能优异
- ✅ **类型安全** - 完整的泛型支持和编译时检查
- ✅ **灵活配置** - 支持 Profile、自定义映射规则
- ✅ **集合支持** - 自动处理 List、Array、IEnumerable 等
- ✅ **循环引用检测** - 自动处理对象间的循环引用
- ✅ **嵌套属性映射** - 支持深层嵌套对象的自动映射
- ✅ **命名规则适配** - 自动处理下划线、驼峰等命名差异

## 快速入门

### 1. 最简单的映射

```csharp
using Ling.Mapper.Extensions;

public class UserDto
{
    public int Id { get; set; }
    public string Name { get; set; }
    public string Email { get; set; }
}

public class UserEntity
{
    public int Id { get; set; }
    public string Name { get; set; }
    public string Email { get; set; }
}

// 使用 Adapt 扩展方法进行映射
var dto = new UserDto
{
    Id = 1,
    Name = "张三",
    Email = "zhangsan@example.com"
};

var entity = dto.Adapt<UserEntity>();
Console.WriteLine($"{entity.Name} - {entity.Email}");
// 输出: 张三 - zhangsan@example.com
```

### 2. 配置全局 Mapper

```csharp
using Ling.Mapper;

// 在应用程序启动时配置
var config = new MapperConfiguration();

// 添加映射配置 Profile
config.AddProfile(new UserProfile());
config.AddProfile(new OrderProfile());

// 创建并设置全局 Mapper 实例
var mapper = config.CreateMapper();
MapperProvider.SetMapper(mapper);
```

## 核心概念

### 1. IMapper 接口

`IMapper` 是映射器的核心接口，提供了四个映射方法：

```csharp
public interface IMapper
{
    // 泛型映射（使用默认选项）
    TDestination? Map<TDestination>(object? source);

    // 泛型映射（使用自定义选项）
    TDestination? Map<TDestination>(object source, AdaptOptions options);

    // 非泛型映射（使用默认选项）
    object? Map(object? source, Type sourceType, Type destType);

    // 非泛型映射（使用自定义选项）
    object? Map(object? source, Type sourceType, Type destType, AdaptOptions options);
}
```

### 2. Adapt 扩展方法

`AdaptExtensions` 提供了一组扩展方法，让映射调用更加简洁：

```csharp
// 基础映射
var target = source.Adapt<TargetType>();

// 使用自定义选项
var target = source.Adapt<TargetType>(AdaptOptions.IgnoreCase);

// 使用后处理回调
var target = source.Adapt<TargetType, SourceType>((dest, src) =>
{
    dest.FullName = $"{src.FirstName} {src.LastName}";
});
```

### 3. MapperProfile

`MapperProfile` 用于定义复杂的映射规则：

```csharp
public class UserProfile : MapperProfile
{
    public UserProfile()
    {
        CreateMap<UserDto, UserEntity>()
            .ForMember(d => d.FullName, s => s.FirstName + " " + s.LastName)
            .Rename(d => d.UserId, "Uid")
            .Ignore(d => d.InternalCode)
            .ReverseMap();
    }
}
```

### 4. AdaptOptions

`AdaptOptions` 是一个标志枚举，用于控制映射行为（注意：默认值是 FlexibleOption，会忽略大小写和下划线）：

```csharp
[Flags]
public enum AdaptOptions
{
    Strict = 0,                                      // 严格匹配（精确匹配属性名）
    IgnoreCase = 1 << 0,                            // 忽略大小写（UserName 匹配 username）
    IgnoreUnderscore = 1 << 1,                      // 忽略下划线（user_name 匹配 UserName）
    IgnoreNullValues = 1 << 2,                      // 源对象中的 null 值不覆盖目标属性

    Default = IgnoreCase | IgnoreUnderscore,        // 默认选项（同 FlexibleOption）
    FlexibleOption = IgnoreCase | IgnoreUnderscore  // 灵活选项（与 Default 相同）
}
```

扩展方法中如果不传递选项，默认使用 `AdaptOptions.Default`：

```csharp
var target = source.Adapt<Target>();  // 等同于 source.Adapt<Target>(AdaptOptions.Default)
```

```csharp
var source = new PersonDto
{
    FirstName = "李",
```

### 2. 集合映射

Ling.Mapper 自动识别并处理集合类型：

```csharp
// List 映射
var dtoList = new List<UserDto>
{
    new UserDto { Id = 1, Name = "User1" },
    new UserDto { Id = 2, Name = "User2" }

var entityList = dtoList.Adapt<List<UserEntity>>();

// 数组映射
UserDto[] dtoArray = new[] { dto1, dto2 };
var entityArray = dtoArray.Adapt<UserEntity[]>();

// IEnumerable 映射
IEnumerable<UserDto> dtoEnum = dtoList;
var entityEnum = dtoEnum.Adapt<IEnumerable<UserEntity>>();
```

### 3. 嵌套对象映射

自动处理嵌套对象：

```csharp
public class OrderDto
{
    public int Id { get; set; }
    public UserDto User { get; set; }

public class OrderEntity
{
    public int Id { get; set; }
    public UserEntity User { get; set; }
    public List<OrderItemEntity> Items { get; set; }

// 一次性映射整个对象图
```

### 4. 使用映射选项

```csharp
public class ApiDto
{
    public string user_name { get; set; }  // 下划线命名
    public int USERID { get; set; }        // 大写命名
}

public class EntityModel
{
    public string UserName { get; set; }   // 驼峰命名
    public int UserId { get; set; }        // 驼峰命名
}

// 使用 FlexibleOption 自动处理命名差异
var entity = apiDto.Adapt<EntityModel>(AdaptOptions.FlexibleOption);

// 或者组合多个选项

    AdaptOptions.IgnoreCase | AdaptOptions.IgnoreUnderscore

```

### 5. 忽略 null 值

```csharp
var source = new UserDto
{
    Name = "张三",
    Email = null  // null 值

{
    Name = "原始名称",

// 使用 IgnoreNullValues，目标对象的 Email 不会被覆盖
var result = source.Adapt<UserEntity>(AdaptOptions.IgnoreNullValues);
// result.Email = "old@example.com" (保持不变)
```

## 高级功能

### 1. 使用 Profile 配置映射

#### 创建 Profile

```csharp
public class OrderProfile : MapperProfile
{
    public OrderProfile()
    {
        CreateMap<OrderDto, OrderEntity>()
            // ForMember: 自定义属性映射
            .ForMember(d => d.TotalAmount, s => s.Price * s.Quantity)
            .ForMember(d => d.DisplayName, s => $"{s.Code} - {s.Name}")

            // Rename: 属性名重命名
            .Rename(d => d.CustomerId, "ClientId")

            // Ignore: 忽略某个属性
            .Ignore(d => d.InternalCode)

            // ReverseMap: 创建反向映射
            .ReverseMap();
    }
}
```

#### 注册 Profile

```csharp
var config = new MapperConfiguration();

// 单个注册
config.AddProfile(new OrderProfile());

// 批量注册
config.AddProfiles(
    new UserProfile(),
    new OrderProfile(),
    new ProductProfile()
);

var mapper = config.CreateMapper();
MapperProvider.SetCurrent(mapper);  // 注意：方法名是 SetCurrent 而不是 SetMapper
```

### 2. ForMember - 自定义属性映射

```csharp
CreateMap<UserDto, UserEntity>()
    // 拼接多个字段
    .ForMember(d => d.FullName, s => s.FirstName + " " + s.LastName)

    // 计算值
    .ForMember(d => d.Age, s => DateTime.Now.Year - s.BirthYear)

    // 条件映射
    .ForMember(d => d.Status, s => s.IsActive ? "Active" : "Inactive")

    // 嵌套属性
    .ForMember(d => d.DepartmentName, s => s.Department.Name);
```

### 3. Rename - 属性重命名

当源属性名和目标属性名不一致时使用：

```csharp
public class ApiResponse
{
    public int uid { get; set; }
    public string user_name { get; set; }
}

public class User
{
    public int UserId { get; set; }
    public string UserName { get; set; }
}

CreateMap<ApiResponse, User>()
    .Rename(d => d.UserId, "uid")
    .Rename(d => d.UserName, "user_name");
```

### 4. Ignore - 忽略属性

```csharp
CreateMap<UserDto, UserEntity>()
    // 忽略敏感信息
    .Ignore(d => d.Password)
    .Ignore(d => d.CreditCard)

    // 忽略内部字段
    .Ignore(d => d.InternalCode)
    .Ignore(d => d.CreatedBy);
```

### 5. ReverseMap - 反向映射标记

```csharp
// 当前版本中 ReverseMap 只设置标记位，返回一个新的反向表达式实例
// 用于方便后续扩展反向映射功能
CreateMap<UserDto, UserEntity>()
    .ForMember(d => d.FullName, s => s.FirstName + " " + s.LastName)
    .ReverseMap();  // 返回 MappingExpression<UserEntity, UserDto>

// 如需实现真正的双向映射，建议分别在两个 Profile 中定义
// UserDto -> UserEntity 的映射
CreateMap<UserDto, UserEntity>()
    .ForMember(d => d.FullName, s => s.FirstName + " " + s.LastName);

// UserEntity -> UserDto 的反向映射需要单独定义
CreateMap<UserEntity, UserDto>()
    .ForMember(d => d.FirstName, s => s.FullName.Split(' ')[0]);
```

### 6. 后处理回调

映射完成后执行自定义逻辑。支持强类型和弱类型两种回调方式：

#### 强类型回调（编译时类型检查）

调用时指定源类型 `TSource`，`src` 参数会有正确的类型推导：

```csharp
var entity = dto.Adapt<UserEntity, UserDto>((dest, src) =>
{
    // dest 的类型是 UserEntity（100% 类型安全）
    // src 的类型是 UserDto（100% 类型安全）
    dest.FullName = $"{src.FirstName} {src.LastName}";
    dest.CreatedAt = DateTime.Now;
    dest.IsProcessed = true;
});

// 带选项的强类型回调
var entity = dto.Adapt<UserEntity, UserDto>(
    AdaptOptions.IgnoreNullValues,
    (dest, src) =>
    {
        dest.UpdatedAt = DateTime.Now;
    }
);
```

#### 弱类型回调（运行时类型）

如果不指定源类型，则 `src` 参数为 `object`：

```csharp
var entity = dto.Adapt<UserEntity>((dest, src) =>
{
    // dest 的类型是 UserEntity?
    // src 的类型是 object（需要运行时类型检查）
    if (dest != null)
    {
        dest.Timestamp = DateTime.Now;
    }
});

// 带选项的弱类型回调
var entity = dto.Adapt<UserEntity>(
    AdaptOptions.IgnoreNullValues,
    (dest, src) =>
    {
        if (dest != null)
        {
            dest.CreatedAt = DateTime.Now;
        }
    }
);
```

#### 集合后处理

回调会对整个集合执行一次（不对每个元素）：

```csharp
var entityList = dtoList.Adapt<List<UserEntity>>((destList, srcList) =>
{
    // 整个集合映射完成后执行这个回调
    Console.WriteLine($"映射了 {destList?.Count} 个对象");

    // 可以对整个列表进行操作
    destList?.Sort((a, b) => a.Id.CompareTo(b.Id));
});
```

### 7. 循环引用处理

Ling.Mapper 自动检测和处理循环引用：

```csharp
public class Node
{
    public int Id { get; set; }
    public string Name { get; set; }
    public Node? RelatedNode { get; set; }
}

// 创建循环引用
var nodeA = new Node { Id = 1, Name = "A" };
var nodeB = new Node { Id = 2, Name = "B" };
nodeA.RelatedNode = nodeB;
nodeB.RelatedNode = nodeA;  // 循环！

// Mapper 会自动检测并打破循环
var target = nodeA.Adapt<Node>();  // 不会 StackOverflow
```

## 配置选项

### 1. MapperConfiguration

```csharp
var config = new MapperConfiguration();

// 设置默认映射选项（如果不设置，Adapt 时会使用 AdaptOptions.Default）
config.DefaultAdaptOptions = AdaptOptions.FlexibleOption;

// 启用严格模式（未匹配的属性会抛异常）
config.StrictMode = true;

// 配置全局约定（应用级别的设置）
config.ConfigureConventions(opt =>
{
    opt.CaseInsensitiveNameMatch = true;      // 属性名不区分大小写（默认 true）
    opt.IgnoreSpecialCharacters = false;       // 是否忽略特殊字符（默认 false）
});

// 添加 Profile（支持单个或批量）
config.AddProfile(new UserProfile());
config.AddProfiles(new UserProfile(), new OrderProfile());

// 创建 Mapper 实例
var mapper = config.CreateMapper();
```

### 2. 全局约定配置

```csharp
config.ConfigureConventions(opt =>
{
    // 属性名匹配时是否忽略大小写（默认 true）
    opt.CaseInsensitiveNameMatch = true;

    // 是否忽略特殊字符进行命名规范化（默认 false）
    // 如果为 true：a_type -> AType
    opt.IgnoreSpecialCharacters = false;
});
```

### 3. 运行时选项

```csharp
// 严格模式（精确匹配属性名）
var result = source.Adapt<Target>(AdaptOptions.Strict);

// 忽略大小写
var result = source.Adapt<Target>(AdaptOptions.IgnoreCase);

// 忽略下划线（user_name 匹配 UserName）
var result = source.Adapt<Target>(AdaptOptions.IgnoreUnderscore);

// 忽略 null 值（source 中的 null 不覆盖 target 属性）
var result = source.Adapt<Target>(AdaptOptions.IgnoreNullValues);

// 组合选项（多个 Flag 可以 | 组合）
var result = source.Adapt<Target>(
    AdaptOptions.IgnoreCase |
    AdaptOptions.IgnoreUnderscore |
    AdaptOptions.IgnoreNullValues
);

// 使用默认选项（默认是 FlexibleOption）
var result = source.Adapt<Target>(AdaptOptions.Default);
```

### 4. 选项优先级

1. **运行时选项** - `Adapt<T>(options)` 参数（优先级最高）
2. **DefaultAdaptOptions** - `config.DefaultAdaptOptions` 设置的值
3. **全局约定** - `config.ConfigureConventions(...)` 配置的约定（优先级最低）

> 注意：`ConfigureConventions` 配置的是 `GlobalConventionOptions`（包含 `CaseInsensitiveNameMatch` 和 `IgnoreSpecialCharacters`），而 `DefaultAdaptOptions` 设置的是 `AdaptOptions`（包含 `IgnoreCase`、`IgnoreUnderscore`、`IgnoreNullValues` 等）。

## 最佳实践

### 1. 应用启动时配置

```csharp
// Program.cs 或 Startup.cs
public class Program
{
    public static void Main(string[] args)
    {
        // 配置 Mapper
        ConfigureMapper();

        // 运行应用
        var builder = WebApplication.CreateBuilder(args);
        // ...
    }

    private static void ConfigureMapper()
    {
        var config = new MapperConfiguration();

        // 添加所有 Profile
        config.AddProfiles(
            new UserProfile(),
            new OrderProfile(),
            new ProductProfile()
        );

        // 设置默认选项
        config.DefaultAdaptOptions = AdaptOptions.FlexibleOption;

        // 创建并设置全局 Mapper
        var mapper = config.CreateMapper();
        MapperProvider.SetMapper(mapper);
    }
}
```

## 性能优化

### 1. 表达式树缓存

Ling.Mapper 使用 `ConcurrentDictionary` 缓存编译后的映射委托：

```csharp
// 第一次调用会编译表达式树
var entity1 = dto1.Adapt<UserEntity>();  // 编译 + 执行

// 后续调用直接使用缓存
var entity2 = dto2.Adapt<UserEntity>();  // 直接执行（极快）
```

### 2. Profile 预热

在应用启动时添加 Profile 会自动预热编译：

```csharp
var config = new MapperConfiguration();
config.AddProfile(new UserProfile());  // 预热编译所有映射规则

var mapper = config.CreateMapper();
// 此时所有 Profile 中的映射已编译完成
```

### 3. 批量映射优化

```csharp
// ✅ 推荐：使用集合映射
var entityList = dtoList.Adapt<List<UserEntity>>();

// ❌ 不推荐：在循环中逐个映射
var entityList = new List<UserEntity>();
foreach (var dto in dtoList)
{
    entityList.Add(dto.Adapt<UserEntity>());
}
```

### 4. 性能基准

## 常见问题

### 1. 属性名不匹配怎么办？

**使用 Rename 或 FlexibleOption：**

```csharp
// 方案 1：使用 Rename
CreateMap<ApiDto, Entity>()
    .Rename(d => d.UserId, "uid");

// 方案 2：使用 FlexibleOption（推荐）
var entity = apiDto.Adapt<Entity>(AdaptOptions.FlexibleOption);
```

### 2. 如何忽略某些属性？

```csharp
// 方案 1：在 Profile 中忽略
CreateMap<User, UserDto>()
    .Ignore(d => d.Password)
    .Ignore(d => d.InternalCode);

// 方案 2：使用 IgnoreNullValues（如果源为 null）
var dto = user.Adapt<UserDto>(AdaptOptions.IgnoreNullValues);
```

### 3. 如何处理复杂的映射逻辑？

```csharp
// 使用 ForMember 自定义逻辑
CreateMap<Order, OrderDto>()
    .ForMember(d => d.TotalPrice, s => s.Items.Sum(i => i.Price * i.Quantity))
    .ForMember(d => d.Status, s => s.IsPaid ? "Paid" : "Pending");
```

### 4. 集合映射失败？

确保目标类型是具体的集合类型：

```csharp
// ✅ 正确
var list = source.Adapt<List<UserDto>>();
var array = source.Adapt<UserDto[]>();

// ❌ 错误：抽象类型可能失败
var collection = source.Adapt<ICollection<UserDto>>();
```

### 5. 循环引用导致 StackOverflow？

Ling.Mapper 会自动检测循环引用，如果仍然出现问题：

```csharp
// 确保使用最新版本 (>= 2.1.3)
// 循环引用会自动处理，不会 StackOverflow
```

### 6. 性能不佳？

```csharp
// 检查 1：确保在启动时注册 Profile（预热编译）
config.AddProfile(new UserProfile());

// 检查 2：避免在循环中创建新的 Mapper
// ❌ 不要这样做
foreach (var item in items)
{
    var config = new MapperConfiguration();  // 每次都创建
    var mapper = config.CreateMapper();
}

// 检查 3：使用批量映射而不是逐个映射
var entityList = dtoList.Adapt<List<Entity>>();  // ✅
```

### 7. 如何映射到现有实例？

当前版本不直接支持映射到现有实例，可以使用后处理：

```csharp
var existingEntity = GetExistingEntity();

var newEntity = dto.Adapt<Entity, Dto>((dest, src) =>
{
    // 手动更新现有实例
    existingEntity.Name = dest.Name;
    existingEntity.Email = dest.Email;
});
```

### 8. null 值处理

```csharp
// 默认行为：null 值会覆盖目标属性
var entity = dto.Adapt<Entity>();  // null 会映射过去

// 忽略 null 值
var entity = dto.Adapt<Entity>(AdaptOptions.IgnoreNullValues);  // null 不映射
```

### 9. 如何调试映射问题？

```csharp
// 启用严格模式查看未匹配的属性
config.StrictMode = true;

// 使用后处理回调查看映射结果
var entity = dto.Adapt<Entity>((dest, src) =>
{
    Console.WriteLine($"映射完成: {dest?.GetType().Name}");
    // 检查属性值...
});
```

## 完整示例

### 实战案例：电商订单系统

```csharp
using Ling.Mapper;
using Ling.Mapper.Extensions;

// 1. 定义 DTO 和 Entity
public class CreateOrderDto
{
    public int UserId { get; set; }
    public List<OrderItemDto> Items { get; set; }
    public string ShippingAddress { get; set; }
}

public class OrderItemDto
{
    public int ProductId { get; set; }
    public int Quantity { get; set; }
    public decimal Price { get; set; }
}

public class Order
{
    public int Id { get; set; }
    public int UserId { get; set; }
    public DateTime CreatedAt { get; set; }
    public decimal TotalAmount { get; set; }
    public string Status { get; set; }
    public List<OrderItem> Items { get; set; }
    public string ShippingAddress { get; set; }
}

public class OrderItem
{
    public int ProductId { get; set; }
    public int Quantity { get; set; }
    public decimal Price { get; set; }
    public decimal Subtotal { get; set; }
}

// 2. 创建 Profile
public class OrderProfile : MapperProfile
{
    public OrderProfile()
    {
        CreateMap<CreateOrderDto, Order>()
            .ForMember(d => d.CreatedAt, s => DateTime.Now)
            .ForMember(d => d.Status, s => "Pending")
            .ForMember(d => d.TotalAmount, s =>
                s.Items.Sum(i => i.Price * i.Quantity))
            .Ignore(d => d.Id);  // Id 由数据库生成

        CreateMap<OrderItemDto, OrderItem>()
            .ForMember(d => d.Subtotal, s => s.Price * s.Quantity);
    }
}

// 3. 配置和使用
public class Program
{
    public static void Main()
    {
        // 配置 Mapper
        var config = new MapperConfiguration();
        config.AddProfile(new OrderProfile());
        config.DefaultAdaptOptions = AdaptOptions.FlexibleOption;

        var mapper = config.CreateMapper();
        MapperProvider.SetMapper(mapper);

        // 创建订单
        var orderDto = new CreateOrderDto
        {
            UserId = 1001,
            ShippingAddress = "北京市朝阳区",
            Items = new List<OrderItemDto>
            {
                new OrderItemDto { ProductId = 1, Quantity = 2, Price = 99.99m },
                new OrderItemDto { ProductId = 2, Quantity = 1, Price = 199.99m }
            }
        };

        // 映射
        var order = orderDto.Adapt<Order>();

        Console.WriteLine($"订单创建时间: {order.CreatedAt}");
        Console.WriteLine($"订单状态: {order.Status}");
        Console.WriteLine($"订单总额: {order.TotalAmount}");
        Console.WriteLine($"商品数量: {order.Items.Count}");
    }
}
```
