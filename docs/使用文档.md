## 选择入口

常用命名空间：

```csharp
using Ling.Mapper;
using Ling.Mapper.Configuration;
using Ling.Mapper.Extensions;
using Ling.Mapper.Models;
using Ling.Mapper.Provider;
```

下文短示例可放在方法体内；涉及 `UserSource` / `UserTarget` 的示例共用本节末尾的模型。

```csharp
var source = new UserSource { Id = 1, Name = "示例" };
var target = source.Adapt<UserTarget>();
var list = new[] { source }.Adapt<List<UserTarget>>();
```

未设置全局实例时，`MapperProvider.Current` 会创建默认 mapper。需要独立配置或避免依赖全局状态时，显式持有 mapper：

```csharp
var mapper = new MapperConfiguration().CreateMapper();
var target = mapper.Map<UserTarget>(source);
var dynamicTarget = mapper.Map(source, typeof(UserSource), typeof(UserTarget));
```

完整选项入口同时支持泛型和显式 Type：

```csharp
var target = mapper.Map<UserTarget>(
    source, AdaptOptions.Default,
    afterMapItem: (destination, original) => { },
    ignoreNames: new[] { "Note" });

var dynamicTarget = mapper.Map(
    source, typeof(UserSource), typeof(UserTarget), AdaptOptions.Default,
    afterMapItem: null, ignoreNames: new[] { "Note" });
```

显式 `sourceType` 必须与实际输入兼容；null Type 参数、非法选项会被拒绝。

示例模型：

```csharp
public sealed class UserSource
{
    public int Id { get; set; }
    public string? Name { get; set; }
    public string? FirstName { get; set; }
    public string? LastName { get; set; }
    public string? AmountText { get; set; }
    public string? Note { get; set; }
    public AddressSource? Address { get; set; }
}

public sealed class AddressSource
{
    public string? City { get; set; }
}

public sealed class UserTarget
{
    public int Id { get; set; }
    public string? Name { get; set; }
    public decimal Amount { get; set; }
    public string? City { get; set; }
    public string? Note { get; set; } = "保留值";
}
```

## 属性匹配与忽略

`AdaptOptions` 是可组合的位标志，不是配置对象：

| 选项 | 行为 |
|---|---|
| Strict | 精确名称匹配，数值为 0；不是默认值 |
| IgnoreCase | 匹配时忽略大小写 |
| IgnoreUnderscore | 匹配时忽略下划线 |
| IgnoreNullValues | 跳过源值为 null 的成员赋值 |
| Default / FlexibleOption | IgnoreCase 与 IgnoreUnderscore 的组合 |
| IgnoreUnderscoreOption | IgnoreUnderscore 的兼容别名 |

```csharp
var exact = source.Adapt<UserTarget>(AdaptOptions.Strict);
var keepNullDefaults = source.Adapt<UserTarget>(
    AdaptOptions.Default | AdaptOptions.IgnoreNullValues);
var ignored = source.Adapt<UserTarget>("Id", "Note");
```

运行时忽略列表填写**目标属性名称**；可忽略不存在的名称，但不能传 null/空白名称。忽略属性不会读取对应源 getter。IgnoreNullValues 不会吞掉格式错误或溢出。

`MapperConfiguration.DefaultAdaptOptions` 用于未传选项的 `IMapper.Map`。当前便捷 `Adapt` 重载自行传入 `AdaptOptions.Default`，不应假设它继承该配置；需要精确匹配时请显式传 `AdaptOptions.Strict`。

## Profile 与显式 mapper

ForMember 决定成员来源表达式，Rename 选择源属性或源嵌套路径，Ignore 跳过目标成员：

```csharp
public sealed class UserProfile : MapperProfile
{
    public UserProfile()
    {
        CreateMap<UserSource, UserTarget>()
            .ForMember(d => d.Name, s => s.FirstName + " " + s.LastName)
            .Rename(d => d.Amount, nameof(UserSource.AmountText))
            .Rename(d => d.City, "Address.City")
            .Ignore(d => d.Note);
    }
}
```

```csharp
var configuration = new MapperConfiguration();
configuration.AddProfile(new UserProfile());
var mapper = configuration.CreateMapper();
var target = mapper.Map<UserTarget>(new UserSource
{
    FirstName = "Ada",
    LastName = "Lovelace",
    AmountText = "12.50",
    Address = new AddressSource { City = "London" }
});
// Name = "Ada Lovelace", Amount = 12.50m, City = "London", Note = "保留值"
```

需要让便捷 Adapt 使用这个实例时，在初始化阶段调用 `MapperProvider.SetCurrent(mapper)`。不要在并发请求中反复重置全局 provider。

边界：

- ForMember、Rename、Ignore 支持 `d => d.Child.Value`。引用中间节点为 null 时需要可写属性及公开无参构造；已有只读引用可写其内部属性，值类型中间节点需要 setter 以写回。嵌套忽略保留同级字段，不应修改源对象。
- 同一目标的 ForMember 重复设置以最后一次为准；Ignore 优先于显式绑定。
- Profile 中 ReverseMap 自动登记反向规则，支持 Rename 与纯属性路径 ForMember（含安全 boxing）。计算表达式在 ReverseMap 调用时明确拒绝，不能靠后续链式 ForMember 补救；此时另写两条 CreateMap。显式独立反向配置优先于自动生成配置。
- ConfigureConventions 的大小写及下划线约定用于默认匹配；优先级为本次显式 AdaptOptions > 显式 DefaultAdaptOptions > conventions。配置在 CreateMapper 前完成。
- 普通目标需公开无参构造函数。StrictMode=false 时缺少构造函数的 IMapper 映射返回 null；StrictMode=true 时抛映射异常。通用 Adapt 同样保留 mapper 的 null 结果，不再另行反射构造目标。显式集合项回调重载的 null 源仍返回空列表。
- StrictMode **不是**“未匹配属性必须报错”；未匹配属性默认保持目标初始值。

## 注册类型转换

仅在内置转换不明确或业务语义特殊时注册规则。例如明确 long 表示 Unix 秒，而非猜测单位：

```csharp
TypeConverterRegistry.Register(
    typeof(long), typeof(DateTimeOffset),
    new Func<long, DateTimeOffset>(DateTimeOffset.FromUnixTimeSeconds));

var instant = 1_700_000_000L.Adapt<DateTimeOffset>();
```

规则签名必须精确匹配注册的源/目标类型。安全直接赋值优先于规则；非 null 的 nullable 值可在没有精确规则时使用底层规则，null 单独处理。详见[转换优先级](转换与诊断.md#转换优先级)。

`TypeConverterRegistry.RegisterJson<T>()` 可注册 `string ↔ T` 的 JSON 转换。JSON、日期单位或加密数据应由显式规则承担语义，而不是任意调用 ChangeType 或 ToString。

## 三类回调

### 对象与来源

```csharp
var target = source.Adapt<UserTarget, UserSource>((destination, original) =>
{
    destination.Name = original.Name + "（已处理）";
});
```

### 集合项与来源项

```csharp
IEnumerable<UserSource> sources = new[] { source };
var targets = sources.Adapt<UserTarget, UserSource>((destination, original) =>
{
    destination.Note = "来源 ID：" + original.Id;
});
```

此重载要求目标项为带公开无参构造函数的引用类型。null 集合源保留返回空列表的兼容行为；null callback 被拒绝。

### 最终结果

```csharp
var targets = sources.Adapt<List<UserTarget>>(result =>
{
    Console.WriteLine(result.Count);
});
```

结果回调在最终结果上调用一次。结果可能为 null，应按业务需要检查。结果回调自己的异常原样传播；映射管线中的项回调异常由 MappingException 安全包装。

整体集合由自定义转换器接管时，不会自动配对源/目标元素调用项回调；元素行为由转换器负责，结果级回调仍适用。

## null 与失败处理

```csharp
var configuration = new MapperConfiguration
{
    NullValueHandling = NullValueHandling.Throw,
    IncludeSourceValueInExceptions = false
};
var mapper = configuration.CreateMapper();

try
{
    mapper.Map<decimal>("not-a-number");
}
catch (MappingException error)
{
    Console.WriteLine(error.Path); // $
    Console.WriteLine(error.DestinationType);
}
```

- 默认 UseDefault：null 到非nullable值类型使用默认值；Throw 改为抛错。
- null 到引用类型或nullable仍为 null。通用 `Adapt<List<T>>(null)` 也是 null，不与专用集合项回调重载混淆。
- 非法值转换不会被当作 null，也不会偷偷跳过成员。
- 默认不包含源值。开启预览时有长度限制及敏感字段脱敏；原异常的 Message/Data/Inner 链不原样保留。

数值舍入、Infinity/NaN、文化区域、日期时区及完整诊断限制统一见[转换与诊断](转换与诊断.md)，本页不重复定义这些契约。

## 集合与对象图

```csharp
var array = new[] { source }.Adapt<UserTarget[]>();
var list = new[] { source }.Adapt<List<UserTarget>>();
```

- 支持的可转换形态包括一维数组、List、可接受 List 的接口，以及有 `IEnumerable<T>` 构造函数的集合。
- 相同或安全可赋值的对象/集合直接赋值，**不是复制**。修改结果可能同时修改源对象。
- 在相同源引用、相同声明目标类型及相同忽略投影下保留支持的循环/共享引用。接口与具体目标类型混用不保证同一目标实例；无法预构造的集合遇循环明确失败。
- 泛型字典分别映射 key/value；转换后 key 冲突或 null 明确失败，不覆盖已有项。运行时 ignoreNames 作用于值成员；字典 key 不进入诊断预览。目标需支持的可变构造或 dictionary/enumerable 构造。非泛型 Hashtable 不自动推断键值类型。
- 无公开 setter 的不可变结构体选择参数可绑定最多且唯一的公开构造函数，支持 optional 默认值；歧义或无法绑定明确失败，空结构体不会伪造成功。被忽略参数用 optional/default(T)，不求源 getter。
- 多维目标数组仍不属于自动转换范围。
- 有符号/无符号数值数组按元素转换与溢出契约处理，不利用 CLR 数组别名重解释数据。

## 并发及验证

配置和 Profile 在 CreateMapper 前完成，之后不要并发修改。mapper 可并发使用；注册规则替换支持后续调用更新，但不承诺同一次对象图始终观察同一版本。不要在每次请求中重复注册规则。

[测试覆盖矩阵](测试覆盖矩阵.md)列出断言证据、运行时与真正缺口，不以“几千 case”代替每种功能的覆盖。测试项目使用控制台入口，`dotnet test` 不会自动执行所有套件；构建、全量执行、时区测试及基准命令见[测试说明](../tests/Ling.Mapper.Tests/README.md)。

生成器接入见[独立 analyzer 包说明](../generators/Ling.Mapper.Generator/README.md)，仅安装 runtime 包不会启用生成。已有显式登记类型对的真实 Source Generator；它只支持受限子集，不执行运行时 Profile、conventions 或 TypeConverterRegistry。Native AOT 实测状态见[新增验证记录](新增功能与验证记录.md)。详情见[架构与 AOT](架构与AOT.md)。性能应在同环境测量，不使用旧演示数字作为发布承诺。

## 忽略投影与自定义规则

非空忽略列表可要求对象/集合建立新的投影，而不再直接复用源引用。整个类型的 opaque converter 无法保证内部忽略规则，因此与非空忽略投影组合明确拒绝；请在 converter 内显式处理，或改用可检查的成员配置。不同投影不会共享同一个缓存目标。生成后端目前只支持顶级忽略名，dotted 忽略路径明确拒绝。
