# 1.2.0：转换契约与回归验证

## 发布范围

本版基于 1.1.3（b7f593a344c8e5c69b45c702ea021d12e98e61a9），保留 Adapt API，整理运行时映射器、标量转换、集合映射和诊断职责。包继续提供 net6.0、net8.0、net9.0、net10.0，不新增 net11.0 发布目标。发布状态以 NuGet 实际可下载版本为准，Git 标签不是发布成功的证明。

### 修复与新增

- 根对象、属性及集合统一使用转换契约；真正执行自定义转换和 ForMember 配置，支持可空规则提升。
- 数字、字符串、枚举、Guid、日期采用明确转换语义和固定文化区域；日期偏移与无偏移输入不依赖服务器时区。
- 增加 NullValueHandling、MappingException 和可配置诊断值预览。错误包含类型、字段路径及脱敏的内部异常信息，不暴露原始异常的数据链。
- 修复跨根映射复用旧对象、并发调用上下文污染、共享引用及循环引用处理。
- 修复 CLR 有符号/无符号数组可赋值判断绕过元素转换的问题。
- 缓存映射计划与转换委托，减少热路径闭包及集合扩容；移除未使用的旧辅助实现。

### 升级时注意

1. 同类型或安全可赋值对象优先直接返回，不保证深复制。
2. 无效转换不再悄悄返回默认值。null 默认仍允许映射为值类型默认值，可配置为抛错。
3. 普通 Adapt 的 null 输入与 IMapper 一致；引用目标返回 null。带逐项回调的专用集合重载保留 null 输入返回空 List 的兼容行为。
4. 不猜测数字日期单位；ticks、秒或毫秒必须显式配置。浮点 NaN/Infinity 遵循对应 BCL 转换行为。
5. 不支持的字典跨类型转换、无明确规则的只读结构体、嵌套目标选择器现在明确报错，不静默丢数据。
6. 异常 InnerException 是脱敏快照，不是原始异常实例。详细规则见[转换与诊断](转换与诊断.md)。

### 性能观察，不作全面提速承诺

.NET 10 同机最终代码与 1.1.3 基线按 AB / BA / AB 顺序交替运行；每进程预热 2000 次、5 轮计时，表中为三个进程中位数的中位数。计时外校验正确性，循环内不打印。

| 场景 | 1.1.3 ns/op | 1.2.0 ns/op | 旧/新 bytes/op |
| --- | ---: | ---: | ---: |
| 普通数字属性 | 214.05 | 230.72 | 120 / 96 |
| 根数字集合 | 1481.93 | 460.31 | 464.03 / 688 |
| 同类型对象 | 211.78 | 198.83 | 120 / 48 |
| 100 项对象集合 | 正确性检查失败，排除耗时比较 | 32935.63 | 不比较 / 18880 |

普通数字属性分配降低，但本次耗时略升；根数字集合更快但分配增加。同类型对象从克隆变为直接赋值，不能当作等价深复制提速。旧对象集合存在跨根陈旧结果复用，不能拿错误结果的耗时做有效基线。

.NET 10 并发度 1 / 2 / 8 的单次记录分别约 395万 / 688万 / 1491万 ops/s，约 96 bytes/op。包含校验和调度成本、分配采用进程统计。共享执行环境有波动，不作为 SLA 或硬性性能门槛。

## 明确未验证或未实现

- 没有 Windows、Native AOT、裁剪发布验证；当前不是源码生成映射器。
- 没有测试每种 CLR 类型与每种用户自定义类型的笛卡尔积；覆盖矩阵保留具体缺口。
- ReverseMap 自动注册和全局约定执行尚不完整，不能视为已支持功能。
- 配置必须先构建再使用；不承诺并发修改 Profile/配置，转换注册表更新也不是整个对象图的事务快照。
- 构建有既有测试可空警告、net6 支持周期警告与候选 SDK 提示；NuGet 审计缓存权限产生 NU1900，不能宣称依赖漏洞审计通过。
