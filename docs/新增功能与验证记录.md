## 功能范围

- 运行时：泛型字典键值转换、不可变结构体构造绑定、nested target 写入/忽略、纯属性路径 ReverseMap 自动登记、global naming conventions。
- 日期默认按真实 AutoMapper 差分对齐；扩展/null差异单列，不算一致项。
- 生成器：assembly GeneratedMap 显式类型对、强类型 DTO/标量代码与已登记元素集合，未登记不退回反射。限制见[架构与 AOT](架构与AOT.md)。
- computed ReverseMap 明确拒绝，使用两条 CreateMap；opaque converter 与非空ignore projection组合拒绝。引用身份保证限定相同源引用、声明目标类型和投影。

## 生成后端与 Native AOT

release-final 使用 SDK 10 ILCompiler + gcc 发布并执行 .NET 10 / Linux x64 原生 ELF，`dynamic-code-supported=False`，62/62 条断言通过，publish/run 均 exit 0。生成后端 JIT smoke 亦为62/62；IL/AOT/trim告警为0。生成歧义保护在getter读取前拒绝，断言包含getter调用0次。源码门控与参数/Unicode补缺均已包含在此次原生结果，不借此前35/59条结果代替。具体其他编译告警以验证清单/日志为准，不把零IL告警泛称整个构建零告警。

仅验证显式生成子集，不据此声称所有 runtime 功能、操作系统或框架均 AOT 兼容。接入方式和编译期拒绝边界见[生成器说明](../generators/Ling.Mapper.Generator/README.md)。

运行时与生成器为两个独立1.3.0包。仅本地打包/验收，不代表NuGet已发布；仅安装runtime包不启用生成器。最终本地独立双包consumer使用全新缓存、仅本地包源及无还原构建，已确认最新62项断言及exit0；同时核对生成器实际输出代码。此JIT消费证据与原生publish/run分开记录。

## 同环境性能配对

.NET 10 净空执行，基线1.2.0与当前1.3.0以 AB / BA / AB 顺序完成三轮配对，按统一执行流程汇总；原始汇总为 `.work/matrix-gaps/fastpath-paired-summary.json`。以下为特定样例的每操作数据，不是通用吞吐保证：

| 样例 | 1.2.0 ns/op | 1.3.0 ns/op | 1.2.0 → 1.3.0 bytes/op |
|---|---:|---:|---:|
| 同型对象 | 219.83 | 204.39 | 48 → 48 |
| 数值成员 | 256.79 | 239.54 | 96 → 96 |
| 100对象集合 | 65322.66 | 58064.08 | 18880 → 18888 |
| 根数字集合 | 514.59 | 494.42 | 688 → 696 |

generic入口省去CLR已保证的冗余类型校验后，此轮四个样例的耗时均低于同轮基线，简单热路径分配持平；两个集合样例仍各增加8 bytes/op。早期根数字集合约22%回退已不再是最终结果，不应继续作为当前结论。不同批次基线有波动，且没有统计置信区间，不能推断所有输入、框架或环境普遍加速。性能不能替代正确性、安全隔离和并发验证。
