# 1.3.1 验证与发布准备

状态：源码准备与本地测试，待最终 commit 绑定打包及手动发布。不要将本页当成 NuGet 已发布证明。

修复仅限 runtime ForMember 来源表达式解析阶段的 NullReferenceException/ArgumentNullException→表达式 default；转换、目标构造/setter、回调及其他异常不吞掉。金额继续使用 Convert.ToInt32，中点取偶、nullable null保留、overflow报错。生成器仅同步包版本，不增加runtime Profile支持。

本地环境：Debian 13 Linux x64，官方 .NET SDK10.0.403/runtime10.0.14，Release。版本号改为1.3.1后最终重跑通过四TFM（net6/net8/net9/net10）编译、net10全量41套件/0失败（原40+新增1）、新增自定义表达式41项断言、独立诊断67项、generated JIT62项；日志记录于本次工作区 v131-* 验收产物，不能将源码阶段当成最终包消费验收。

边界覆盖 null/empty UTF8、来源成员链、值/nullable结果、主动抛null相关异常、显式fallback、IgnoreNullValues及初始化器、单次getter、不可变结构体参数、金额舍入/溢出、FormatException、Nullable.Value异常、转换器/自动getter/setter/构造/回调错误、嵌套和集合诊断路径。

限制：只实际执行net10，其他框架编译不等于运行；旧演示套件仍存在部分未断言输出。本轮Native AOT因既有MSBuild task-host与sandbox launcher限制不重复绕行，不能宣称1.3.1原生执行已验证。没有映射到既有目标实例API；不在补丁中扩展class构造支持。独立审核通过不等于NuGet发布。
