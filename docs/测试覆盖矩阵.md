# 支持契约与测试覆盖矩阵

审计日期：2026-10-23。此文档按**可观察契约**而不是测试数量评估覆盖；不声称穷尽任意 CLR 类型、用户委托、对象图或输入值。

## 证据、标记与运行范围

- **A**：存在实际比较、引用身份、异常类型/路径等断言。只覆盖列出的数据与位置。
- **L**：历史用例含明确条件检查或断言，但并非整个 suite 的全部打印内容都被验证。
- **缺**：本次审计尚未找到对应断言，不能从邻近用例推断已覆盖。
- **边界**：尚未实现、明确不支持或需先确定契约。负面拒绝行为也必须有断言。
- 位置：**R** 根值、**M** 成员、**C** 集合元素/容器、**N** 嵌套图。状态：正常、边界、失败、恢复。

## 六、运行能力与明确未验范围

- `GeneratedMapperFactoryProxy` 返回 false，是真实占位，不是已交付 Source Generator。
- Native AOT发布、裁剪、禁用动态代码后的解释路径：**未验**。R4全部CoreCLR结果不能替代这些测试。
- .NET 11为RC2；本页不承诺正式版、所有OS/架构或所有TFM。SDK编译成功与目标runtime实际执行需分开记录。
- 性能基准验证的是所选数据规模与场景，不能替代正确性矩阵；额外分配、首编译竞争及规则频繁更新需独立分析。
- 任意第三方converter内部日志、线程安全与副作用不由库的安全诊断测试保证。

## 七、新增证据与真正剩余范围

NB的5764项是131×11×4，包含成功结果和预期失败；并非5764种业务功能。比较oracle为独立BCL Convert.ChangeType而非调用生产ScalarConversion；boxed值Equals也检查目标CLR类型，但不检查负零bit/NaN payload。

PC关闭了参数验证、常见反射成员、结构拒绝和回调边界空缺；其“nested destination must work or reject”与KVP用例允许正确支持或显式拒绝。当前实现走拒绝分支，不能据此宣传实现嵌套目标写入或跨类型字典。

DC已增加**真实同时运行的writer/readers**，不是只在写完后并发读。它要求交错阶段每次转换仅看见相邻合法版本且结果字段一致，结束后只能看到最终版本；不要求整个对象图版本原子一致，也未覆盖多个writer。缓存代GC释放、长期高基数key内存上界仍仅源码审查，缺专门证据。

尚未实现或明确不支持：真实Source Generator/Native AOT；自动跨类型字典及immutable/empty struct转换（可显式注册规则）；嵌套目标ForMember/Rename/Ignore；ReverseMap自动登记、ConfigureConventions改变计划未实现。创建后并发改Profile/config不属于支持契约。

真正剩余覆盖：所有API入口与每种失败的完整笛卡尔积；ScalarConversion直接参数契约；所有enum/日期/nullable规则组合在四位置的边界矩阵；private ctor/abstract/interface和open generic/byref/pointer/void；嵌套Rename中间null/private getter；HashSet/Queue/非零下界数组/多IEnumerable类型；provider热重配置并发；多writer和GC长期测试；Unicode截断及间接敏感数据分类。它们不能用已有case数消除，也不意味着均应扩展为产品支持。

新增NB/PC/DC已随最终冻结快照在四runtime完成；12TZ仅重跑CR，不应误写为NB/PC/DC也经过全部TZ。历史演示仍为L或未断言，未升级成A。

## 八、赋值判定的只读复核

当前根级MapValue、BuildPlan、成员直接赋值/基类实际值分支，以及公开ScalarConversion均使用同一IsSafelyAssignable判定，拒绝CLR对有符号/无符号数组的位模式别名直赋，转而做元素转换或按标量边界拒绝。NB一维数值数组实际结果和类型验证覆盖核心误差；递归集合协变判定有visited防循环，不等于所有自定义集合形态都已测试。GetElementType按数组元素或实际IEnumerable<T>接口取型，不再把任意单泛型类的参数误当元素。多IEnumerable<T>实现的歧义仍未专门约定或测试。本轮只读复核未发现这些路由的新阻塞。
