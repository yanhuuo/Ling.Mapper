## 简介

**Ling.Mapper** 是一个高性能、零配置的 .NET 对象映射库，专为简化对象之间的转换而设计。它基于 Expression Tree 编译技术，提供接近手写代码的性能，同时保持简洁易用的 API。

### 🎯 设计目标

1. **零配置** - 开箱即用，自动识别同名属性
2. **高性能** - 基于编译表达式树，避免反射开销
3. **类型安全** - 编译时类型检查，减少运行时错误
4. **功能完整** - 支持嵌套对象、集合、循环引用等复杂场景
5. **易于扩展** - 支持自定义映射规则和类型转换器

### ⚡ 性能数据

| 场景 | 吞吐量 | 说明 |
|------|--------|------|
| 简单对象 | **975K ops/sec** | 三个属性的简单对象 |
| 复杂对象 | **148K ops/sec** | 包含嵌套对象和集合 |
| 集合映射 | **8.5M elements/sec** | 100个元素的列表 |
| 枚举转换 | **2M ops/sec** | 枚举与整数互转 |
| 可空类型 | **1.5M ops/sec** | nullable与non-nullable转换 |

### ✅ 已支持的功能

#### 1. 零配置映射
```csharp
// 无需任何配置，自动匹配同名属性
var target = source.Adapt<TargetType>();
```

#### 2. 嵌套对象映射
```csharp

public class Order
```

- `List<T>`
- `IList<T>`

- `IEnumerable<T>`

#### 4. 类型转换
- 枚举 ↔ 整数
- Nullable ↔ Non-Nullable
- 自定义类型转换器
- JSON 字符串 ↔ 对象

#### 5. 循环引用检测
```csharp

{
```
```csharp
    public int Id { get; set; }

var dto = new UserDto 
{

    Email = "zhangsan@example.com"
```

## 核心功能详解

### 1. Adapt 扩展方法

#### 1.1 基础用法
```csharp
// 最简单的用法
var target = source.Adapt<TargetType>();

// 使用指定的 Mapper
var target = source.Adapt<TargetType>(mapper);
```

#### 1.2 自定义回调
```csharp
// 映射后进行自定义处理
var target = source.Adapt<TargetType>((dest, src) =>
{
    dest.CreatedAt = DateTime.Now;
    dest.UpdatedBy = "System";
});
```

#### 1.3 使用运行时选项
```csharp
// 使用 FlexibleOption 处理命名差异
var target = source.Adapt<TargetType>(AdaptOptions.FlexibleOption);

// 自定义选项
var options = new AdaptOptions
{
    IgnoreCase = true,
    IgnoreUnderscore = true,
    IgnoreNullValues = true,
    IgnoreProperties = new[] { "Password", "Token" }
};
var target = source.Adapt<TargetType>(options);
```

### 2. MapperConfiguration 配置

#### 2.1 全局配置
```csharp
var config = new MapperConfiguration();

// 配置命名约定
config.ConfigureConventions(opt =>
{
    opt.CaseInsensitiveNameMatch = true;
});

// 设置默认 AdaptOptions
config.SetDefaultAdaptOptions(AdaptOptions.FlexibleOption);

var mapper = config.CreateMapper();
MapperProvider.SetCurrent(mapper);
```

#### 2.2 使用 Profile
```csharp
public class UserProfile : MapperProfile
{
    public UserProfile()
    {
        // 配置 UserDto -> UserViewModel
        CreateMap<UserDto, UserViewModel>(cfg =>
        {
            // 自定义属性映射
            cfg.ForMember(dest => dest.FullName, 
                src => $"{src.FirstName} {src.LastName}");
            
            // 忽略属性
            cfg.Ignore(dest => dest.InternalId);
            
            // 嵌套属性路径
            cfg.ForMember(dest => dest.CityName, 
                src => "Address.City.Name");
        });
    }
}

// 注册 Profile
config.AddProfile(new UserProfile());
```

### 3. 类型转换器

#### 3.1 注册 JSON 转换器
```csharp
// 注册 JSON 转换器（自动处理 JSON 字符串 ↔ 对象）
TypeConverterRegistry.RegisterJson<ExtraInfoModel>();

public class Activity
{
    public string ExtraInfoJson { get; set; }  // JSON 字符串
}

public class ActivityDto
{
    public ExtraInfoModel ExtraInfo { get; set; }  // 对象
}

var dto = activity.Adapt<ActivityDto>();
// ExtraInfoJson 自动反序列化为 ExtraInfo 对象
```

#### 3.2 注册自定义转换器
```csharp
// 单向转换
TypeConverterRegistry.Register<string, DateTime>(str => 
{
    return DateTime.TryParse(str, out var dt) ? dt : DateTime.MinValue;
});

// 双向转换
TypeConverterRegistry.Register<int, string>(i => i.ToString());
TypeConverterRegistry.Register<string, int>(s => int.TryParse(s, out var i) ? i : 0);
```

### 4. AdaptOptions 运行时配置

#### 4.1 FlexibleOption（推荐）
```csharp
// 处理各种命名差异
var source = new 
{ 
    user_name = "张三",   // 下划线
    user_age = 25,       // 下划线
    UserEmail = "xxx"    // 帕斯卡
};

var target = source.Adapt<UserInfo>(AdaptOptions.FlexibleOption);
// 自动匹配：user_name -> UserName, user_age -> UserAge, UserEmail -> UserEmail
```

#### 4.2 自定义选项
```csharp
var options = new AdaptOptions
{
    IgnoreCase = true,              // 忽略大小写
    IgnoreUnderscore = true,        // 忽略下划线
    IgnoreNullValues = true,        // 源属性为 null 时不覆盖目标属性
    IgnoreProperties = new[] { "Password", "Token" }  // 忽略指定属性
};

var target = source.Adapt<TargetType>(options);
```

## 高级功能

### 1. 嵌套属性路径映射 (A.B.C.D)

#### 场景说明
将嵌套对象的深层属性映射到目标对象的扁平属性。

#### 示例
```csharp
// 源对象（嵌套结构）
public class SourceModel
{
    public User User { get; set; }
}

public class User
{
    public Profile Profile { get; set; }
}

public class Profile
{
    public string Name { get; set; }
    public int Age { get; set; }
}

// 目标对象（扁平结构）
public class TargetModel
{
    public string UserName { get; set; }
    public int UserAge { get; set; }
}

// 配置映射
var config = new MapperConfiguration();
config.CreateMap<SourceModel, TargetModel>(cfg =>
{
    cfg.ForMember(dest => dest.UserName, src => "User.Profile.Name");
    cfg.ForMember(dest => dest.UserAge, src => "User.Profile.Age");
});

var mapper = config.CreateMapper();
MapperProvider.SetCurrent(mapper);

// 使用
var source = new SourceModel
{
    User = new User
    {
        Profile = new Profile { Name = "张三", Age = 25 }
    }
};

var target = source.Adapt<TargetModel>();
Console.WriteLine($"{target.UserName}, {target.UserAge}岁");
// 输出: 张三, 25岁
```

### 2. 循环引用处理

#### 场景说明
处理对象图中的循环引用，避免 StackOverflow。

#### 示例
```csharp
public class Node
{
    public string Name { get; set; }
    public Node Parent { get; set; }
    public List<Node> Children { get; set; }
}

public class NodeDto
{
    public string Name { get; set; }
    public NodeDto Parent { get; set; }
    public List<NodeDto> Children { get; set; }
}

// 创建循环引用
var root = new Node { Name = "Root" };
var child1 = new Node { Name = "Child1", Parent = root };
var child2 = new Node { Name = "Child2", Parent = root };
root.Children = new List<Node> { child1, child2 };

// Ling.Mapper 自动检测并处理循环引用
var dto = root.Adapt<NodeDto>();
// 不会 StackOverflow，自动打破循环
```

### 4. 枚举转换

#### 场景说明
自动处理枚举与整数之间的转换。

#### 示例
```csharp
public enum UserStatus
{
    Inactive = 0,
    Active = 1,
    Suspended = 2
}

public class UserDto
{
    public UserStatus Status { get; set; }
}

public class UserViewModel
{
    public int Status { get; set; }  // 枚举 -> 整数
}

var dto = new UserDto { Status = UserStatus.Active };
var viewModel = dto.Adapt<UserViewModel>();
Console.WriteLine(viewModel.Status);  // 输出: 1

// 反向转换
public class UserInput
{
    public int Status { get; set; }  // 整数 -> 枚举
}

public class UserEntity
{
    public UserStatus Status { get; set; }
}

var input = new UserInput { Status = 2 };
var entity = input.Adapt<UserEntity>();
Console.WriteLine(entity.Status);  // 输出: Suspended
```

### 5. 可空类型处理

#### 场景说明
自动处理 Nullable 与 Non-Nullable 类型之间的转换。

#### 示例
```csharp
public class SourceModel
{
    public int? Age { get; set; }
    public string Name { get; set; }
}

public class TargetModel
{
    public int Age { get; set; }      // nullable -> non-nullable
    public string Name { get; set; }
}

// null 值自动转换为默认值
var source1 = new SourceModel { Age = null, Name = "张三" };
var target1 = source1.Adapt<TargetModel>();
Console.WriteLine(target1.Age);  // 输出: 0

// 有值正常转换
var source2 = new SourceModel { Age = 25, Name = "李四" };
var target2 = source2.Adapt<TargetModel>();
Console.WriteLine(target2.Age);  // 输出: 25

// 反向转换
public class TargetModel2
{
    public int? Age { get; set; }  // non-nullable -> nullable
}

var target3 = source2.Adapt<TargetModel2>();
Console.WriteLine(target3.Age.HasValue);  // 输出: True
```

## 常见问题

### Q1: 如何处理属性名不匹配的情况？

**A:** 使用 `AdaptOptions.FlexibleOption` 或配置映射规则。

```csharp
// 方式 1: 使用 FlexibleOption（推荐）
var target = source.Adapt<TargetType>(AdaptOptions.FlexibleOption);

// 方式 2: 配置映射规则
CreateMap<Source, Target>(cfg =>
{
    cfg.ForMember(dest => dest.TargetName, src => src.SourceName);
});
```

### Q2: 如何忽略某些属性？

**A:** 使用 `Ignore` 方法或 `AdaptOptions`。

```csharp
// 方式 1: 配置 Profile
CreateMap<Source, Target>(cfg =>
{
    cfg.Ignore(dest => dest.Password);
    cfg.Ignore(dest => dest.Token);
});

// 方式 2: 使用 AdaptOptions
var options = new AdaptOptions
{
    IgnoreProperties = new[] { "Password", "Token" }
};
var target = source.Adapt<TargetType>(options);
```

### Q3: 如何处理复杂的类型转换？

**A:** 注册自定义类型转换器。

```csharp
// 注册转换器
TypeConverterRegistry.Register<string, DateTime>(str =>
{
    return DateTime.TryParse(str, out var dt) ? dt : DateTime.MinValue;
});

// 或在 Profile 中使用 ForMember
CreateMap<Source, Target>(cfg =>
{
    cfg.ForMember(dest => dest.CreatedAt, 
        src => DateTime.Parse(src.CreatedAtString));
});
```

### Q4: 性能如何？

**A:** Ling.Mapper 基于 Expression Tree 编译，性能接近手写代码：

- 简单对象：**975K ops/sec**
- 复杂对象：**148K ops/sec**
- 集合映射：**8.5M elements/sec**

详见[性能优化文档](./Performance_Optimization_v2.1.4.md)。

### Q5: 是否支持循环引用？


### Q6: 如何映射嵌套属性（如 A.B.C.D）？

### 2. 映射配置示例

#### MapperConfig.cs
```csharp
public static class MapperConfig
{
    public static void Initialize()
    {
        var config = new MapperConfiguration();
        
        // 全局配置
        config.ConfigureConventions(opt =>
        {
            opt.CaseInsensitiveNameMatch = true;
        });
        
        // 注册所有 Profile
        config.AddProfile(new UserProfile());
        config.AddProfile(new OrderProfile());
        config.AddProfile(new ProductProfile());
        
        // 注册类型转换器
        TypeConverterRegistry.RegisterJson<ExtraInfoModel>();
        TypeConverterRegistry.Register<string, DateTime>(str => 
            DateTime.TryParse(str, out var dt) ? dt : DateTime.MinValue);
        
        // 设置默认选项
        config.SetDefaultAdaptOptions(AdaptOptions.FlexibleOption);
        
        // 创建并设置全局 Mapper
        var mapper = config.CreateMapper();
        MapperProvider.SetCurrent(mapper);
    }
}
```

### 3. Profile 组织示例

#### UserProfile.cs
```csharp
public class UserProfile : MapperProfile
{
    public UserProfile()
    {
        // Entity -> DTO
        CreateMap<User, UserDto>(cfg =>
        {
            cfg.ForMember(dest => dest.FullName, 
                src => $"{src.FirstName} {src.LastName}");
            cfg.Ignore(dest => dest.Password);
        });
        
        // DTO -> Entity
        CreateMap<UserDto, User>(cfg =>
        {
            cfg.Ignore(dest => dest.CreatedAt);
            cfg.Ignore(dest => dest.UpdatedAt);
        });
        
        // DTO -> ViewModel
        CreateMap<UserDto, UserViewModel>();
    }
}
```

### 4. 在服务中使用

```csharp
public class UserService
{
    private readonly IUserRepository _repository;
    
    public async Task<UserViewModel> GetUserByIdAsync(int id)
    {
        // 从数据库获取实体
        var user = await _repository.GetByIdAsync(id);
        
        // 映射到视图模型
        var viewModel = user.Adapt<UserViewModel>();
        
        return viewModel;
    }
    
    public async Task<UserDto> CreateUserAsync(CreateUserRequest request)
    {
        // 映射到实体
        var user = request.Adapt<User>(dest =>
        {
            dest.CreatedAt = DateTime.UtcNow;
            dest.Id = 0;  // 新建对象，ID 由数据库生成
        });
        
        // 保存到数据库
        await _repository.AddAsync(user);
        
        // 映射到 DTO 返回
        return user.Adapt<UserDto>();
    }
}
```

```csharp
public class UserMappingTests
```
